## 🛠️ How to Contribute

### 1. Fork & Clone
```bash
# Fork the repository on GitHub, then clone your fork:
git clone https://github.com/viroaryan/rahul-tube.git
cd rahul-tube
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
The app will be available at `http://localhost:5173` with fast hot-module replacement (HMR), proxying API requests to the backend server on `http://localhost:5000`.

### 4. Create a Feature Branch
```bash
git checkout -b feature/amazing-new-feature
```

### 5. Run Verification & Tests
Before submitting a PR, ensure all tests pass and the production bundle builds without errors:
```bash
npm run build
npm test
```

### 6. Commit & Push
```bash
git commit -m "feat: add amazing new feature"
git push origin feature/amazing-new-feature
```

### 7. Open a Pull Request
Go to [GitHub](https://github.com/viroaryan/rahul-tube/pulls) and click **"New Pull Request"**.

---

## 📋 Coding Guidelines
* Write clean, readable JavaScript and React code (ES6+ and functional components with hooks).
* Style components using Tailwind CSS utility classes.
* Avoid adding unnecessary heavy dependencies.
* Ensure all features work in both dark mode and mobile views.
